# Evaluating and Choosing models

> Diagnostic: a test to gain insight into what is/isn't working with a learning algorithm, to gain guidance into improving its performance.

_e.g._ Linear regression on housing price

It makes a unacceptatbly large errors in predictions. What do you try next?

- Get more training data
- Try smaller sets of features
- Try getting additional featues
- Try adding polynomial features
- Try decreasing $\lambda$
- Try increasing $\lambda$

> $\lambda$ is the regularization to reduce overfitting. (mentioned in 2.2.2)

Before trying any attempt, run a diagnostic first.  
Once you understand `bias` and `variance`, you will know what to try.

**First you need to know how to evaluate and choose models.**

## Evaluating a model

> Indicate the performance of a model.

Basica procedure (take linear regression as an example):

1. Split the data set into 2 subsets, a `training set` (_e.g._ 70%) and a `test set` (_e.g._ 30%),
2. Fit parameters using `training set` by minimizing cost function $J$:
   $$J(\vec{w},b)=\min_{\vec{w},b}\left[\frac{1}{2m_{train}}\sum_{i=1}^{m_{train}}(f_{\vec{w},b}(\vec{x}^i)-y^i)^2 + \frac{\lambda}{2m_{train}}\sum_{j=1}^{n}w_j^2\right]$$
3. To tell how well this model is doing, compute test error using `test set`:
   $$J_test(\vec{w},b) = \frac{1}{2m_{test}} \left[\sum_{i=1}^{m_{test}}(f_{\vec{w},b}(\vec{x}_{test}^i)-y_{test}^i)^2\right] $$

   > For linear regression, compute `MSE`  
   > For binary classification, compute `Logistic Loss`, `Accuracy`  
   > For multi-lable classification. compute `Categorical Cross-Entropy`, `Accuracy`

   Additionally, to get a measure of how well your learning algorithm is doing, compute train error using `train set`:  
   $$J_train(\vec{w},b) = \frac{1}{2m_{train}} \left[\sum_{i=1}^{m_{train}}(f_{\vec{w},b}(\vec{x}_{train}^i)-y_{train}^i)^2\right] $$

## Model selection

> You can evaluate the performance of a model by computing $J_{test}$.  
> **However**, you would get an optimistic estimate of generalization error (might be lower than the actual value), because one extra parameter (e.g., $d$, the degree of polynomial, like $d=3, \space f_{\vec{w},b}(x)=\vec{w_1}x+\vec{w_2}x^2+\vec{w_3}x^3+b$) is used in train set.

**Better procedure:**

1. Split the data set into 3 subsets, a `training set` (_e.g._ 60%), a `cross-validation set` (_e.g._ 20%), and a `test set` (_e.g._ 20%),
2. Fit parameters using training set,
3. Choose the degree of polynomial using cross-validation set,
   $$\text{Cross validation error:} \space J_{cv}(\vec{w},b) = \frac{1}{2m_{cv}}[\sum_{i=1}^{m_{cv}}(f_{\vec{w},b}(\vec{x^i})-y^i)^2]$$
4. Estimate generalization error using test set,
   $$\text{Test error:} \space J_{test}(\vec{w},b) = \frac{1}{2m_{test}}[\sum_{i=1}^{m_{test}}(f_{\vec{w},b}(\vec{x^i})-y^i)^2]$$
5. Select the model with a low $J_{cv}$

Similarly, this procedure also works for choosing among other types of models (e.g., choosing a neural network architecture).
