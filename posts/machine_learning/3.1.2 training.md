# Neural Network (2): Training

## Traning details

_e.g._ Two handwritten digits

Given set of (x, y) examples
How to build and train this in code?

```python
import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Dense
from tensorflow.keras.losses import BinaryCrossentropy

# 1. Specify the model
model = Sequential([
    Dense(units=25, activation='sigmoid'),
    Dense(units=15, activation='sigmoid'),
    Dense(units=1, activation='sigmoid'),
])

# 2. Specify loss and cost
# in classification, BinaryCrossentropy is similar to sigmoid
# in regression, MeanSquareError is suitable
model.compile(loss=BinaryCrossentropy())
# 3. Train on data to minimize $J(\vec{w}, b)$
# compute derivatives for gradient decent using "backpropagation"
# 100 steps in grandient decent
model.fit(X,Y,epochs=100)
```

## Choosing activation functions

![common_activations.png](3.1.2%20training_files/common_activations.png)

**Output Layer**

- none (linear regression): $g(z)=z$
  > When $y=+/-$
- sigmoid: $g(z)=\frac{1}{1+e^{-z}}$
- ReLU: $g(z)=max(x,z)$
  > When $y\geq0$

**Hidden Layer**

`ReLU` is the most common choice  
Why?

1. faster than sigmoid
2. flat in only one place (influence the speed of gradient descent)

So, the example mentioned before could be modified:

```python
model = Sequential([
    Dense(units=25, activation='relu'),
    Dense(units=15, activation='relu'),
    Dense(units=1, activation='sigmoid'),
])
```

Other activation function: tanh, leaky ReLU, swish...

> Why do we need activation functions?

In a 2 layers nerual network, it's not different with linear regression if we don't use activation functions.

$$
\begin{aligned}
a^{[1]} &= w_1^{[1]}x+b_1^{[1]} \\
a^{[2]} &= w_1^{[2]}a^{[1]}+b_1^{[2]} \\
        &= w_1^{[2]}(w_1^{[1]}x+b_1^{[1]})+b_1^{[2]} \\
        &= (w_1^{[2]}w_1^{[1]})x+(w_1^{[2]}b_1^{[1]}+b_1^{[2]}) \\
        &= wx+b
\end{aligned}
$$
