# Linear Regression with Mutiple Vaiable

**Notations**

| GeneraNotation  | Description                                       | _e.g._                           |
| --------------- | ------------------------------------------------- | -------------------------------- |
| n               | number of features                                | 4 ($j<4$)                        |
| $x_j$           | $j^{th}$ feature                                  | $x_1$=[2104]                     |
| $\vec{x}^{(i)}$ | feautes of $i^{th}$ training example              | $\vec{x}^{(1)}$=[2104, 5, 1, 45] |
| $x_j^{(i)}$     | value of feature $j$ in $i^{th}$ training example | $x_1^{(1)}$=2104                 |

## **Model:**

$$
\begin{align*}
f_{w,b}(\vec{x})
&= \vec{w}·\vec{x}+b \\
&= w_1x_1+w_2x_2+···+w_nx_n+b
\end{align*}
$$

> from: $$f_{w,b}(x)=w_1x_1+w_2x_2+···+w_nx_n+b$$
> simplify with: $$\vec{x}=[x_1, x_2,x_3, ···, x_n]$$
> and $$\vec{w}=[w_1, w_2,w_3, ···, w_n]$$  
> and b is a number

## Vectorization

> make cod shorter and make it run much more efficiently


## **Cost function:** $J(\vec{w},b) = \frac{1}{2m} \sum_{i=1}^{m}( f_{\vec{w},b}(\vec{x}^{(i)}) - y^{(i)})^2$

```python
def compute_cost(x, y, w, b):

    m = len(x)

    # cost = 0
    # for i in range(m):
    #     f_wb = np.dot(x[i], w) + b
    #     cost += (f_wb - y[i]) ** 2
    # cost = cost / (2 * m)

    f_wb = np.dot(x, w) + b

    cost = np.sum((f_wb - y) ** 2) / (2 * m)

    return cost
```

## **Gradient descent**

$$
\begin{aligned}
& w_j = w_j-\alpha\frac{1}{m}\sum_{i=1}^m(f_{\vec{w},b}(\vec{x}^{(i)})-y^{(i)})x_j^{(i)} \\
& \quad = w_j-\frac{\partial}{\partial_{w_j}}J(\vec{w},b) \\
& b = b - a \frac{1}{m}\sum_{i=1}^m (f     {\vec{w},b}(\vec{x}^{(i)})-y^{(i)})
\end{aligned}
$$

```python
def compute_gradient(x, y, w, b):

    m = len(x)
    # n = len(x[0])

    # dj_dw = [0 for _ in range(n)]
    # dj_db = 0
    # for i in range(m):
    #     f_wb = np.dot(x[i], w) + b
    #     for j in range(n):
    #         dj_dw[j] += (f_wb - y[i]) * x[i][j]
    #     dj_db += f_wb - y[i]
    # dj_dw = [dw / m for dw in dj_dw]
    # dj_db /= m

    f_wb = np.dot(x, w) + b

    errors = f_wb - y

    dj_dw = np.dot(x.T, errors) / m
    dj_db = np.sum(errors) / m

    return dj_dw, dj_db
```
