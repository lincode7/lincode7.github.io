## Regularization and bais/variance

> How $\lambda$ affects the bais and variance, and the overall performance of the algorithm.  
> `Summary`: **For high bais, increasing $\lambda$ is likely to help.**

_e.g._ Model:

$$
\begin{aligned}
& f_{\vec{w},b}(x)=w_1x+w_2x^2+w_3x^3+w_4x^4+b \\
& J(\vec{w},b)=\frac{1}{2m}\sum_{i=1}^{m}(f_{\vec{w},b}(\vec{x}^i)-y^i)^2 + \frac{\lambda}{2m}\sum_{j=1}^{n}w_j^2 \\
\end{aligned}
$$

| $\lambda$ | $J_{train}$ | $J_{train}$ | result        | _e.g._                                          |
| --------- | ----------- | ----------- | ------------- | ----------------------------------------------- |
| large     | large       |             | high bias     | $\lambda =10,000$, $w \approx 0$, $y \approx b$ |
| small     | small       | large       | high variance | $\lambda =0$                                    |

**How to choose a approporate $\lambda$?**  
Try different value of $\lambda$,  
Evaluate the cross-validation error,  
Pick a value that has low cross-validation error.

## Establish a basseline level of performance

> Helpful to judge wether $J_{train}$ is high or not.

When analyzing speech recognition, it's useful to measure `Human level performance` because of the noise in the audio.

| Human level performance | $J_{train}$ | $J_{cv}$ |                                                       |
| ----------------------- | ----------- | -------- | ----------------------------------------------------- |
| 10.6%                   | 10.8%       | 14.8 %   | $\text{gap2}^2$ is large<br/>high variance            |
| 10.6%                   | 15.0%       | 15.8 %   | $\text{gap1}^1$ is large<br/>high bais                |
| 10.6%                   | 15.8%       | 19.8 %   | both of them is large<br/>high bais and high variance |

> gap1: the gap between Human level performance and $J_{train}$  
> gap2: the gap between $J_{train}$ and $J_{cv}$

## What to try next with a unacceptable large errors in prediction?

_e.g._ Linear regression on housing price _(the same example in the begining of the diagnoistics section)_

It makes a unacceptatbly large errors in predictions. What do you try next?

```plaintext
Get more training data            -> fixes high variance
Try smaller sets of features      -> fixes high variance
Try getting additional featues    -> fixes high bais
Try adding polynomial features    -> fixes high bais
Try decreasing λ                  -> fixes high bais
Try increasing λ                  -> fixes high variance
```

## Bias/variance and neural networks

> Large nerual networks are low bias machines.

- A simple recipe that isn't always applicable, but if it applies, it can be very powerful for getting an accurate model using a neural network.

  1.  Does it do well on the training set?  
      No -> `High bias` -> Bigger network (more hidden layers or more hidden units per layer)  
      Yes -> 2
  2.  Does it do well on the cross validation set?  
      No -> `High variance` -> More data  
      Yes -> Done

- A large neural network will usually do as well or better than a smaller one so long as regularization is chosen appropriately.

  ```python
  model = Sequential([
     Dense(units=25, activation='relu', kernel_regularizer=L2(0.01))
     Dense(units=15, activation='relu', kernel_regularizer=L2(0.01))
     Dense(units=1, activation='sigmoid', kernel_regularizer=L2(0.01))
  ])
  ```

  > Too simple model (_e.g._ $f_{\vec{w},b}(x)=w_1x+b$), high chance of `High bias`.  
  > Too complex model (_e.g._ $f_{\vec{w},b}(x)=w_1x+w_2x^2+w_3x^3+w_4x^4+b$), high chance of `High variance`.
