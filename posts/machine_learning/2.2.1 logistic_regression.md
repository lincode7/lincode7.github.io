# Logistic Regression

> 'S'-shaped curve, sigmoid formula: $ g(z) = \frac{1}{1+e^{-z}} \phantom{00} 0<g(z)<1 $

## **Modle**: $ f\_{\vec{w},b} (\vec{x}) = g(\vec{w} \cdot \vec{x} + b) = \frac{1}{1+e^{-(\vec{w} \cdot \vec{x} + b)}}$

It is built up with two steps:

1. straight-line function (linear regression): $ z = \vec{w} \cdot \vec{x} + b $
2. 's'-shaped curve function: $ g(z) = \frac{1}{1+e^{-z}} $

Its output shows the "probability" that class is 1

## Decision Boundary

> 0.5 is a common shoice, so we have:  
> $ g(z) = 0.5 => z = \vec{w} \cdot \vec{x} + b = 0 $

## **Cost Function**:

$$
\begin{align*}
J(\vec{w},b)
&= \frac{1}{m} \sum_{i=1}^{m} [L(f_{\vec{w},b}(\vec{x}^{(i)}),y^{(i)})] \tag{1} \\
&= -\frac{1}{m} \sum_{i=1}^{m} [y^{(i)} \log(f_{\vec{w},b}(\vec{x}^{(i)})) + (1-y^{(i)})\log(1 - f_{\vec{w},b}(\vec{x}^{(i)}))]
\end{align*}
$$

**Logical loss function**

> the loos of a signle traning example

$$
L(f_{\vec{w},b}(\vec{x}^{(i)}),y^{(i)}) =
\begin{cases}
-\log(f_{\vec{w},b}(\vec{x}^{(i)})) & \text{if } y^{(i)} = 1 \\
-\log(1 - f_{\vec{w},b}(\vec{x}^{(i)})) & \text{if } y^{(i)} = 0
\end{cases}
$$

Because $y$ can only take on the values of ether 1 or 0, it can be **simplified** to:

$$ L(f*{\vec{w},b}(\vec{x}^{(i)}),y^{(i)}) = -y^{(i)} \log(f*{\vec{w},b}(\vec{x}^{(i)})) - (1-y^{(i)})\log(1 - f\_{\vec{w},b}(\vec{x}^{(i)})) $$

```python
import numpy as np


def sigmoid(z):
    return 1 / (1 + np.exp(-z))


def compute_cost(x, y, w, b):

    # m = len(x)

    #         cost += -np.log(1 - f_wb)
    # cost /= m

    z = np.dot(w, x) + b
    f_wb = sigmoid(z)

    cost = -np.mean(y * np.log(f_wb) + (1 - y) * np.log(1 - f_wb))

    return cost
```
