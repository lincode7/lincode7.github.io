# Inference

**Terminologies**  
| term | description |
| --- | --- |
| layer | a group of neurons which take as input the same input vector, each performing its own computing, and that in turn output a vector for the next layer together |
| activations | the output values of a layer after applying a non-linear activation function (_e.g._ Sigmoid) |
| input layer | the first layer that receives the raw input data without performing computation |
| output layer | the final layer that produces predictions or results |
| hidden layer | any layer between the input and output layers where computation and feature transformation happen|

**Architecture**

1. How many hidden layers are needed?
2. How many neurons are needed in each hidden layer?

- Output: the identity of the person

## How to construct a layer of neurous?

- Simple neural network  
   ![image.png](3.1.1%20inference_files/image.png)  
   Notations  
   | notation | decription |
  | --- | --- |
  | layer 0 | input layer |
  | layer 1 | the first hidden layer |
  | $\vec a^{[1]}$ | the output of layer 1 |
  | $\vec w_1^{[1]}, b_1^{[1]}$ | the parameters of the first unit in layer 1 |

- More complex neural network  
   ![image.png](3.1.1%20inference_files/image1.png)
  Notations  
   | notation | description |
  | - | - |
  | a_j^{[l]} | activation value of layer $l$, unit(neuron)$j$ |
  | g | sigmoid |
  | $\vec w_j^{[l]}, b_j^{[l]}$ | parameters w & b of layer $l$, unit $j$ |
  | \vec a^{[l-1]} | output of layer $l-1$ (previous later) |

  Compute the activation of layer $l$, unit(neuron)$j$:  
   $$ a_j^{[l]} = g\left(\vec w_j^{[l]} \cdot \vec a^{[l-1]} + b_j^{[l]} \right) $$

## Inference: making predictions (**forward propagation**)

> Signals propagate forward from the input layer by applying the core computation at each layer and neuron, ultimately yielding the final output.

### Inference in Code (**TensorFlow**)

e.g. Coffee roasting  
![image.png](3.1.1%20inference_files/image2.png)

- Input: the temperature and duration of toasting
- Output: taste good or not

```python
x = np.array([[200.0, 17.0]])
layer_1 = Dense(units=3, activation="sigmoid")
a1 = layer_1(x)
layer_2 = Dense(units=1, activation="sigmoid")
a2 = layer_2(a1)
print("good" if a2 >= 0.5 else "bad")
```

e.g. Digit classification  
![image.png](3.1.1%20inference_files/image3.png)

```python
x = np.array([[0.0,...,245,...,240,...,0]])
layer_1 = Dense(units=25, activation="sigmoid")
a1 = layer_1(x)
layer_2 = Dense(units=15, activation="sigmoid")
a2 = layer_2(a1)
layer_3 = Dense(units=1, activation="sigmoid")
a3 = layer_3(a2)
print("1" if a3 >= 0.5 else "0")
```
