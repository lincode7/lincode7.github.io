# Linear Regression with One Vaiable

**Notations**

> Traning set: data used to train the model

| General Notation | Description                           |
| ---------------- | ------------------------------------- |
| $x$              | "input" variable                      |
| $y$              | "output" variable or target" variable |
| $m$              | number of training examples           |
| $(x, y)$         | a single training example             |
| $(x^i, y^i)$     | $i^{th}$ training example             |
| $(w,b)$          | parameters, coefficients, or weights  |

## **Model:** $f_{w,b}(x) = wx+b$

$\hat{y} = f(x) = f_{w,b}(x) = wx+b$

> $\hat{y}$ is the prediciton of model $f_{w,b}(x)$

## **Cost function:**

$$
\begin{align*}
J(w,b)
&= \frac{1}{2m} \sum_{i=1}^m(\hat{y}^i - y^i)^2 \\
&= \frac{1}{2m} \sum_{i=1}^m(f_{w,b}(x)^i - y^i)^2
\end{align*}
$$

- Objective:  
  Get the best fit line.
- How cost funtion work?  
  By visualizing the J(w,b) and find the minimum to understand.

> Rather than manually read a contour plot for the best value for $w$ and $b$, an efficient algorithm for automatically finding the values of parameters $w$ and $b$ that given you the best fit line that minimizes the cost funtion J.

```python
import numpy as np


def compute_costt(x, y, w, b):

    m = len(x)

    # cost = 0
    # for i in range(m):
    #     f_wb = w * x[i] + b
    #     cost += (f_wb - y[i]) ** 2
    # cost = cost / (2 * m)

    # np vectorization
    f_wb = w * x + b
    errors = (f_wb - y) ** 2
    cost = np.sum(errors) / (2 * m)

    return cost
```

## **Gradient descent algorithm:**

- Objective: Minimize $J(w,b)$
- Ooutline:  
   Start with some $w$, $b$  
   Keep changing $w$, $b to reduce $J(w,b)$  
   Until we settle at or near a minimum (may have >1 minimums)

> A vivid association: Standing at the top of a hill, then **spinning** around 360 degrees and find a **direction** to go downhill as quickly as possible, repating again and again

### **Implement**: ($w$ and $b$ has initial values.)

1. Compute the gradient

   $$
   \begin{aligned}
   \frac{\partial}{\partial_w} J(w,b)
   &= \frac{\partial}{\partial_w} \frac{1}{2m}\sum_{i=1}^m(wx^{(i)}+b-y^{(i)})^2 \\
   &= \frac{\partial}{\partial_w} \frac{1}{2m}\sum_{i=1}^m(wx^{(i)}+b-y^{(i)})^2 \\
   &= \frac{1}{2m}\sum_{i=1}^m(wx^{(i)}+b-y^{(i)})2x^{(i)} \\
   &= \frac{1}{m}\sum_{i=1}^m(wx^{(i)}+b-y^{(i)})x^{(i)} \tag{2}
   \end{aligned}
   $$

   $$
   \begin{aligned}
   \frac{\partial}{\partial_b} J(w,b)
   &= \frac{\partial}{\partial_w} \frac{1}{2m}\sum_{i=1}^m(wx^{(i)}+b-y^{(i)})^2 \\
   &= \frac{1}{2m}\sum_{i=1}^m(wx^{(i)}+b-y^{(i)})2 \\
   &= \frac{1}{m}\sum_{i=1}^m(wx^{(i)}+b-y^{(i)}) \tag{1}
   \end{aligned}
   $$

```python
def compute_gradient(x, y, w, b):

    m = len(x)

    # dj_dw = 0
    # dj_db = 0
    # for i in range(m):
    #     f_wb = w * x[i] + b
    #     dj_dw += (f_wb - y[i]) * x[i]
    #     dj_db += f_wb - y[i]
    # dj_dw /= m
    # dj_db /= m

    f_wb = w * x + b

    errors = f_wb - y

    dj_dw = np.dot(errors, x) / m
    dj_db = np.sum(errors) / m

    return dj_dw, dj_db
```

2. Simultaneous update $w$ and $b$

   > Performs batch gradient descent to learn theta. Updates theta by taking num_iters gradient steps with learning rate alpha

   $$
   \begin{align*}
   &\text{repeat until convergence:} \lbrace \\
   & \phantom{0000} w := w -  \alpha \frac{\partial J(w,b)}{\partial w} \tag{3}  \\
   & \phantom{0000} b := b -  \alpha \frac{\partial J(w,b)}{\partial b} \\
   & \rbrace
   \end{align*}
   $$

   | Notation                             | description                                                                                                                                                   |
   | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
   | $:=$                                 | value assignment                                                                                                                                              |
   | $\alpha$                             | the learning rate.<br />In usual, it's a small positive number between 0 and 1 (_e.g._ 0.01).<br />It basically controls how big of a step you take downhill. |
   | $\frac{\partial J(w,b)}{\partial_w}$ | the derivative term of J(w,b) with repect to$w$                                                                                                               |
   | $\frac{\partial J(w,b)}{\partial_b}$ | the derivative term of J(w,b) with repect to$b$                                                                                                               |

```python
import copy


def gradient_descent(x, y, w, b, cost_func, gradient_func, alpha, num_iters):

    m = len(x)

    # An array to store cost J at each iteration — primarily for graphing later
    J_history = []

    # avoid modifying global w within function
    _w = copy.deepcopy(w)
    _b = b

    for i in range(num_iters):
        dj_dw, dj_db = gradient_func(x, y, _w, _b)
        _w = _w - alpha * dj_dw
        _b = _b - alpha * dj_db

        if i % 10 == 0 and i < 100000:  # prevent resource exhaustion
            cost = cost_func(x, y, _w, _b)
            J_history.append(cost)

    return _w, _b, J_history
```

3. How to choose a $\alpha$?

   | too small           | too large                                                  |
   | ------------------- | ---------------------------------------------------------- |
   | Will take long time | Might skip the minimum, fail to converge and even diverge. |
