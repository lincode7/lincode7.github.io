# Other Layer Types

## Dense Layer

Each neuron connects to all neurons in the previous layer (receives all of the previous layer's activation outputs), with unique weights for eatch connection.

![dense.png](3.1.5%20other_layer_types_files/dense.png)

## Convolutional Layer

Each neuron connects to a a small, spatially contiguous regionof the previous layer (receives a small, spatially contiguous region of the previous layer's activation outputs), with same weights for each connection.

![convolutional.png](3.1.5%20other_layer_types_files/convolutional.png)
