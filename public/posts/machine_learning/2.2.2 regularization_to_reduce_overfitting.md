# Regularization to Reduce Overfitting

## Overfiting Problem

Common Cause: Too much features with insufficient data

Address:

1. Collect more data
2. Select features
   - Feature selection (in course 2)
3. Reduce size of parameter $w_j$
   - Regularization

## Regularization Cost Funtion

$$
J(\vec{w},b) = \frac{1}{2m} \sum_{i=1}^{m}( f_{\vec{w},b}(\vec{x}^{(i)}) - y^{(i)})^2 + \frac{\lambda}{2m} \sum_{j=1}^{n} w_j^2
$$

$\frac{\lambda}{2m} \sum_{j=1}^{n} w_j^2$ is regularizaiton term, which keep $w_j$ small  
$\lambda > 0 $, is regularization parameter

**See what would happen using different $\lambda$**

1. $\lambda = 0 $: not using regularization, might overfit

2. $\lambda = 10^{10} $: enormous, causing $ w*j \approx 0 $, so $ f*{\vec{w},b}(\vec{x}) = b $ and underfit

### Regularization Linear Rgression

**Cost funtion** _(mentioned before)_

```python
%run "../2.1 linear_regression/2.1.2 linear_regression_with_multiple_variable.ipynb"

import numpy as np


def compute_cost_linear_reg(x, y, w, b, lambda_):
    m, n = x.shape
    reg_term = (lambda_ / (2 * m)) * np.sum(w**2)
    cost = compute_cost(x, y, w, b) + reg_term
    return cost
```

**Gradient decient** _(new)_

$$
\begin{align*}
& \frac{\partial}{\partial w_j} J(\vec{w},b) = \frac{1}{m}\sum_{i=1}^m(wx^{(i)}+b-y^{(i)})x_j^{(i)} + \frac{\lambda}{m}w_j \tag{1} \\
& \frac{\partial}{\partial_b} J(\vec{w},b) = \frac{1}{m}\sum_{i=1}^m(wx^{(i)}+b-y^{(i)}) \tag{2}\\
& \text{repeat until convergence:} \lbrace \\
& \quad w_j := w_j -  \alpha \frac{\partial J(\vec{w},b)}{\partial w_j} \\
& \quad b := b -  \alpha \frac{\partial J(\vec{w},b)}{\partial b} \tag{3}\\
& \rbrace
\end{align*}
$$

```python
def compute_gradient_linear_reg(x, y, w, b, lambda_):
    m, n = x.shape
    dj_dw, dj_db = compute_gradient(x, y, w, b)
    dj_dw += (lambda_ / m) * w
    return dj_dw, dj_db
```

Why $w_j$ will be shrinked

$$
\begin{align*}
w_j
:&= w_j -  \alpha \frac{\partial J(\vec{w},b)}{\partial w_j} \\
&= w_j-\alpha \frac{\lambda}{m} w_j - \alpha \frac{1}{m} \sum_{i=1}^{m}(f_{\vec{w},b}(\vec{x}^{(i)})-y^{(i)}) x_j^{(i)} \\
&= w_j(1-\alpha\frac{\lambda}{m}) - \alpha \frac{1}{m} \sum_{i=1}^{m}(f_{\vec{w},b}(\vec{x}^{(i)})-y^{(i)}) x_j^{(i)}
\end{align*}
$$

### Regularization Logistic Rgression

**Cost Fuction** _(new)_

$$
\begin{align*}
J(\vec{w},b)
&= -\frac{1}{m} \sum_{i=1}^{m} [y^{(i)} \log(f_{\vec{w},b}(\vec{x}^{(i)})) + (1-y^{(i)})\log(1 - f_{\vec{w},b}(\vec{x}^{(i)}))] + \frac{\lambda}{2m}\sum_{j=1}^nw_j^2
\end{align*}
$$

%run "2.2.1 classification.ipynb"
