# Practical Tips for Linear Regression

## **Feature Scaling** (encouraged to do)

> Make gradient descent run much faster

**When we need it?**

> With mutiple features  
> When the range of $x_j$ is
>
> 1. **too small**: $-0.001 \leq x_j \leq 0.001$
> 2. **too large**: $-100 \leq x_j \leq 100$
> 3. or **pretty large compared to other** scaled features: $90 \leq x_j 100$ when others are in $[0,1]$

### 1. **Max scaling**

> When $x$ is all positive  
> Map the range of $x_j$ to $[0,1]$ by $x_j = \frac{x_j}{max\_x_j}$

```python
import numpy as np
import matplotlib.pyplot as plt

x_1 = np.array(
    [
        0,
        23,
        100,
        123,
        200,
        211,
        300,
        876,
        4123,
    ]
)

x_1_scaled = x_1 / x_1.max()
print("original:", x_1)
print("after max scaling:", x_1_scaled)

plt.scatter(range(len(x_1)), x_1, label="original")
plt.scatter(range(len(x_1_scaled)), x_1_scaled, label="scaled")
plt.legend()
plt.show()
```

### 2. **Mean normalization**

> 1. Calculate the mean: $\mu_j$
> 2. Map the range of $x_j$ to $[-1,1]$ by $x_j = \frac{x_j-\mu_j}{max\_x_j-min\_x_j}$

```python
x_1_scaled = (x_1 - x_1.mean()) / (x_1.max() - x_1.min())
print("original:", x_1)
print("after mean normalization:", x_1_scaled)

plt.scatter(range(len(x_1)), x_1, label="original")
plt.scatter(range(len(x_1_scaled)), x_1_scaled, label="scaled")
plt.legend()
plt.show()
```

### 3. **Z-score normalization**

> 1. Calculate the standard deviation: $\sigma_j$
> 2. Let $\mu_j$ around 0, and $\sigma_j$ close to 1 by $x_j = \frac{x_j-\mu_j}{\sigma_j}$

```python
x_1_scaled = (x_1 - x_1.mean()) / x_1.std()
print("original:", x_1)
print("mean:", x_1.mean())
print("std:", x_1.std())
print("after z-score:", x_1_scaled)
print("after z-score, mean:", x_1_scaled.mean())
print("after z-score, std:", x_1_scaled.std())

plt.scatter(range(len(x_1)), x_1, label="original")
plt.scatter(range(len(x_1_scaled)), x_1_scaled, label="scaled")
plt.legend()
plt.show()
```

## Checking Gradient Descent for Convergence

> Plot the "learning curve"  
> Vertical: $j(\vec{w},b)$  
> Horizon: iterations (not w or b)  
> Find out how many iterations is needed

**Autonmatic convergence test**

1. Let $\epsilon = 10^{-3}$
2. If $j(\vec{w},b) \leq \epsilon$, stop the process

**Choose the appropriate $\alpha$**

1. Indentify problem with learning curve
2. Values of $\alpha$ to try: $0.001, 0.01, 0.1, 1$
