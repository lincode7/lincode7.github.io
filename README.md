# 个人主页 - GitHub Pages

一个现代化的个人主页，展示博客文章、兴趣爱好和联系信息。

## 功能特性

- 🏠 **首页**：个人信息、联系方式和博客统计
- 📝 **博客系统**：标签云、文章列表、Markdown渲染
- 🎮 **兴趣主页**：游戏、电影、音乐、旅行记录
- 🌓 **暗黑模式**：支持自动切换和手动切换
- 📱 **响应式设计**：适配各种设备屏幕
- ⚡ **性能优化**：代码分割、懒加载、PWA支持
- 🔍 **SEO优化**：完整的元标签和结构化数据
- 🚀 **自动部署**：GitHub Actions 自动部署到 GitHub Pages

## 技术栈

- **前端框架**：React 18 + TypeScript
- **路由**：React Router DOM
- **样式**：CSS Modules + CSS Variables
- **图表**：D3.js (标签云)
- **Markdown**：React Markdown + 语法高亮
- **图标**：Lucide React
- **构建工具**：Create React App
- **部署**：GitHub Pages + GitHub Actions
