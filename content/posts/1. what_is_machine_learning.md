# **algorithms:**

## 1. **supervised** learning

> learn from data **labled** with the "**right answer**", like a input-output mapping:

| input             | output           | application         |
| ----------------- | ---------------- | ------------------- |
| email             | spam?            | spam filter         |
| autdio            | text transcripts | speech recognition  |
| English           | Spannish         | machine translation |
| ad, user info     | click?           | online ad           |
| image, radar info | position of cars | self-driving car    |
| image of phone    | defect?          | visual inspection   |

- **Regression**: predict a number, infinitely many possible outputs

- **Classification**: predict categories, small number of possible outputs

> most important: find the boundary line

## 2. **unsupervised** learning

> find somthing interesting (e.g. structure, pattern) in **unlabled** data

* **Clastering:** group similar data points together
* **Anomaly detection:** find ususal data points
* **Dimensionally reduction:** compress data useing fewer number
