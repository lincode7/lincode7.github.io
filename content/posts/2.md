## 概述

TypeScript 的类型系统不仅提供了基本的类型检查，还包含了一套完整的类型编程能力。通过高级类型特性，我们可以创建灵活、可重用的类型定义，显著提升代码的类型安全性和开发体验。

## 条件类型 (Conditional Types)

条件类型允许我们根据输入类型来选择输出类型，类似于 JavaScript 中的三元运算符。

```typescript
type IsString<T> = T extends string ? true : false;

type A = IsString<"hello">; // true
type B = IsString<42>; // false
```

## infer 关键字

infer 关键字用于在条件类型中提取类型信息：

```typescript
type ReturnType<T> = T extends (...args: any[]) => infer R ? R : never;

type Func = () => string;
type R = ReturnType<Func>; // string
```

## 映射类型 (Mapped Types)

映射类型允许我们基于现有类型创建新的类型：

```typescript
// 让所有属性变为可选
type Partial<T> = {
  [P in keyof T]?: T[P];
};

// 让所有属性变为只读
type Readonly<T> = {
  readonly [P in keyof T]: T[P];
};

// 让所有属性变为必填
type Required<T> = {
  [P in keyof T]-?: T[P];
};

// 实际使用
interface User {
  id?: number;
  name?: string;
}

type RequiredUser = Required<User>;
// { id: number, name: string }
```

## 模板字面量类型 (Template Literal Types)

TypeScript 4.1 引入了模板字面量类型，可以像字符串模板一样操作类型：

```typescript
type EventName = "click" | "scroll" | "mousemove";
type HandlerName = `on${Capitalize<EventName>}`;

// 'onClick' | 'onScroll' | 'onMousemove'

// 更复杂的例子
type PropGetter<T extends string> = {
  [K in `get${Capitalize<T>}`]: () => string;
};

type UserProps = PropGetter<"name" | "age">;
// { getName: () => string, getAge: () => string }
```

## 实用类型工具

1. **Pick 和 Omit**

```typescript
interface Todo {
  title: string;
  description: string;
  completed: boolean;
  createdAt: number;
}

// 选择特定属性
type TodoPreview = Pick<Todo, "title" | "completed">;
// { title: string, completed: boolean }

// 排除特定属性
type TodoInfo = Omit<Todo, "completed" | "createdAt">;
// { title: string, description: string }
```

2. **Extract 和 Exclude**

```typescript
type T0 = Extract<"a" | "b" | "c", "a" | "f">; // 'a'
type T1 = Exclude<"a" | "b" | "c", "a" | "b">; // 'c'

// 实际应用：过滤函数类型
type FunctionKeys<T> = {
  [K in keyof T]: T[K] extends Function ? K : never;
}[keyof T];

type Methods<T> = Pick<T, FunctionKeys<T>>;
```

## 递归类型

TypeScript 支持递归类型定义，这对于处理嵌套数据结构非常有用：

```typescript
// JSON值的类型定义
type JSONValue =
  | string
  | number
  | boolean
  | null
  | JSONValue[]
  | { [key: string]: JSONValue };

// 深度只读
type DeepReadonly<T> = {
  readonly [P in keyof T]: T[P] extends object ? DeepReadonly<T[P]> : T[P];
};

interface NestedObject {
  a: {
    b: {
      c: string;
    };
  };
}

type ReadonlyNested = DeepReadonly<NestedObject>;
```

## 类型守卫和自定义类型保护

```typescript
// 类型守卫函数
function isString(value: unknown): value is string {
  return typeof value === "string";
}

// 自定义类型保护
interface Cat {
  meow(): void;
}

interface Dog {
  bark(): void;
}

function isCat(pet: Cat | Dog): pet is Cat {
  return (pet as Cat).meow !== undefined;
}

function petAction(pet: Cat | Dog) {
  if (isCat(pet)) {
    pet.meow(); // TypeScript知道这是Cat类型
  } else {
    pet.bark(); // TypeScript知道这是Dog类型
  }
}
```

## 实际应用案例

### 1. API 响应类型安全

```typescript
// 定义API响应格式
interface ApiResponse<T = any> {
  data: T;
  status: number;
  message: string;
}

// 使用泛型约束
async function fetchApi<T>(endpoint: string): Promise<ApiResponse<T>> {
  const response = await fetch(endpoint);
  return response.json();
}

// 使用时获得类型安全
interface User {
  id: number;
  name: string;
  email: string;
}

const userResponse = await fetchApi<User>("/api/user/1");
// userResponse.data的类型是User
```

### 2. 表单验证

```typescript
// 定义表单字段
type FormField<T> = {
  value: T;
  error?: string;
  touched: boolean;
};

// 表单状态类型
type FormState<T extends Record<string, any>> = {
  [K in keyof T]: FormField<T[K]>;
} & {
  isValid: boolean;
  isSubmitting: boolean;
};

// 使用示例
interface LoginForm {
  email: string;
  password: string;
  rememberMe: boolean;
}

type LoginFormState = FormState<LoginForm>;
```

## 性能考虑

1. 避免深度递归：过深的递归类型可能导致编译性能问题
2. 使用 interface 而非 type：对于对象类型，interface 有更好的性能
3. 合理使用条件类型：复杂的条件类型会增加编译时间

## 总结

TypeScript 的高级类型系统为我们提供了强大的工具来构建类型安全的应用程序。通过合理运用这些特性，我们可以：

1. 减少运行时错误
2. 提高代码可维护性
3. 获得更好的 IDE 支持
4. 编写更健壮、可扩展的代码

掌握 TypeScript 的类型编程能力，是成为一名优秀 TypeScript 开发者的关键一步。
