## 引言

自从 React 16.8 引入 Hooks 以来，函数组件的能力得到了极大的增强。Hooks 让我们可以在不编写 class 的情况下使用 state 和其他 React 特性。本文将深入探讨常用 Hooks 的工作原理和使用技巧。

## 核心 Hooks 详解

### 1. useState

`useState` 是最基础的 Hook，用于在函数组件中添加状态。

```jsx
import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>当前计数: {count}</p>
      <button onClick={() => setCount(count + 1)}>增加</button>
    </div>
  );
}
```

**注意事项：**

- 状态更新是异步的
- 多个状态更新会被批处理
- 可以使用函数式更新

### 2. useEffect

`useEffect` 用于处理副作用操作，可以看作是 componentDidMount、componentDidUpdate 和 componentWillUnmount 的组合。

```jsx
import { useState, useEffect } from "react";

function Timer() {
  const [seconds, setSeconds] = useState(0);

  useEffect(() => {
    const interval = setInterval(() => {
      setSeconds((s) => s + 1);
    }, 1000);

    // 清理函数
    return () => clearInterval(interval);
  }, []); // 空依赖数组，只在组件挂载时执行

  return <div>已经过去 {seconds} 秒</div>;
}
```

**依赖数组的三种情况：**

- 空数组 []：只在组件挂载和卸载时执行
- 有依赖 [dep1, dep2]：依赖变化时执行
- 不提供：每次渲染都执行

### 3. useMemo 和 useCallback

这两个 Hook 用于性能优化，避免不必要的计算和渲染。

```jsx
import { useMemo, useCallback, useState } from "react";

function ExpensiveComponent({ items }) {
  // 缓存计算结果
  const filteredItems = useMemo(() => {
    return items.filter((item) => item.active);
  }, [items]);

  // 缓存函数引用
  const handleClick = useCallback(() => {
    console.log("处理点击");
  }, []);

  return (
    <div>
      <button onClick={handleClick}>点击</button>
      <ul>
        {filteredItems.map((item) => (
          <li key={item.id}>{item.name}</li>
        ))}
      </ul>
    </div>
  );
}
```

## 自定义 Hooks

自定义 Hook 是复用状态逻辑的最佳方式。它其实就是一个普通的 JavaScript 函数，但在其中可以调用其他 Hook。

```jsx
// 自定义Hook：获取窗口尺寸
function useWindowSize() {
  const [windowSize, setWindowSize] = useState({
    width: window.innerWidth,
    height: window.innerHeight,
  });

  useEffect(() => {
    function handleResize() {
      setWindowSize({
        width: window.innerWidth,
        height: window.innerHeight,
      });
    }

    window.addEventListener("resize", handleResize);

    return () => window.removeEventListener("resize", handleResize);
  }, []);

  return windowSize;
}

// 使用自定义Hook
function ResponsiveComponent() {
  const { width, height } = useWindowSize();

  return (
    <div>
      窗口尺寸：{width} x {height}
    </div>
  );
}
```

## 最佳实践

1. 只在最顶层使用 Hooks
   - 不要在循环、条件或嵌套函数中调用 Hook
2. 仅在 React 函数中调用 Hooks
   - 在 React 函数组件中调用
   - 在自定义 Hook 中调用
3. 合理的依赖数组
   - 确保依赖数组包含所有外部依赖
   - 使用 eslint-plugin-react-hooks 进行代码检查
4. 性能优化
   - 使用 React.memo 避免不必要的重新渲染
   - 合理使用 useMemo 和 useCallback
   - 使用 React DevTools Profiler 分析性能瓶颈

## 常见问题解答

**Q: 为什么有时候 useEffect 会执行两次？**
A: 在开发环境下，React 会故意执行两次来帮助你发现 bug。生产环境下不会出现这种情况。

**Q: 如何获取上一次的状态值？**
A: 可以使用 useRef 配合 useEffect，或者使用函数式更新。

**Q: 多个 useState 调用是合并更新吗？**
A: 在 React 18 中，多个 setState 调用会被自动批处理，但前提是它们在同一事件循环中。

## 总结

React Hooks 彻底改变了我们编写 React 组件的方式。它们让逻辑复用变得更加简单，代码也更加清晰。掌握 Hooks 不仅能让你的 React 应用更加高效，还能让你更好地理解 React 的设计哲学。
